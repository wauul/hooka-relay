# 2026-09-22: Circuit breaker and explicit status

## Context
Repeated failures need protection across worker replicas. The existing breaker has automatic recovery, not a permanent terminal disabled state.

## Decision
Preserve the endpoint lease, failure threshold, cooldown and half-open probe. Expose OPEN as DISABLED in API responses; retain userStatus separately for pause.

## Consequences
Clients see an explicit status while stored user intent and automatic probes retain their behavior. Pauses hold pending work; incidents notify through existing Resend and the outbox.
