# 2026-09-22: TTL + DLX retries

## Context
Shared free RabbitMQ plans cannot enable arbitrary plugins. The delayed-message plugin itself is open source; hosted plan support is the limitation.

## Decision
Keep durable TTL queues, two exchange bindings, publisher confirms and the Postgres outbox watchdog. Configure retry schedules by selecting existing queue names.

## Consequences
Existing queue TTLs and default schedules never change silently. Broker dead-letter losses remain recoverable from the outbox.
