# Landing page search positioning

Primary intent: **webhook delivery service for SaaS teams**. Related terms used where they describe actual capabilities: outbound webhooks, signed webhooks, webhook retries, delivery logs, failure investigation, replay.

The homepage, documentation, privacy and terms pages are the only sitemap entries. Other pages receive `X-Robots-Tag: noindex, nofollow` from the Next.js proxy, including the changing service status view, authenticated routes, signup and login, password and verification flows, invitation links and customer portal links. Robots, sitemap and preview image files remain crawlable. The robots file permits crawling so crawlers can observe private-page response headers. The homepage canonical resolves to `https://hooka-relay.com` (equivalent to the root URL with a trailing slash).

The English and French interface preference currently uses the same URL and a cookie. The server renders the cookie-selected language, while the browser toggle changes it without navigation. There is no `hreflang` because there are no separate stable language URLs. For multilingual search later, create crawlable `/en/` and `/fr/` routes with complete translated content, self canonicals and reciprocal `hreflang` links before advertising French as a search language.

The main repository has no root license, so the landing page does not call the hosted service open source. The current Terms of Use say the hosted service is free and subject to resource limits, but the landing page does not turn that current term into an enduring pricing promise. The homepage includes `WebSite` structured data with the name Hooka Relay and the canonical domain, matching its visible branding. There are no fabricated ratings, reviews or ranking claims.

The production domain is `https://hooka-relay.com`. Cloudflare provides DNS, Vercel serves HTTPS, and `www.hooka-relay.com` redirects to the root domain. Public pages on the previous Vercel hostname permanently redirect to this domain; existing API clients can still use the old hostname. New SDK source defaults and all current examples use the new domain. Previously published SDK packages require an explicit new base URL until a new package release is published.

Verify the `sc-domain:hooka-relay.com` property in Google Search Console and submit `https://hooka-relay.com/sitemap.xml`. Keep the Google verification TXT record in Cloudflare. Request indexing for the homepage and documentation after deployment. Search Console is the source for indexing and query performance; submission does not guarantee indexing, timing, or ranking for the brand or other keywords.
